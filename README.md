# QUIZZEC

Projeto feito em **React-Native** que consome **API** para a criação de um jogo de quizes alimentados pelos 
próprios usuários!

--- 

## Sobre o projeto

O QUIZZEC foi criado com o intuito de consolidar os conhecimentos apredidos em React-Native, consumindo API
online (jsonbin.io). Fazendo requisições HTTP, tratando a resposta ou enviado dados dos quizes alimentados pelos jogadores

Focos de aprendizado:

- GET e POST em API
- React-Native em Expo

## Funcionalidade 

- Criar quizes
- Compartilhar via QR code
- Acessar quizes listados
- Jogar quizes criados por usuarios de qualquer lugar

## Tecnologias utilizadas

- React-Native com Expo
- TypeScript
- npm
- jsonbin.io

## Requisitos

Antes de iniciar, certifique-se de ter instalado em sua máquina:

* Node.js (versão LTS recomendada)
* npm, yarn ou pnpm
* Git
* Expo Go (no celular) ou emulador configurado

---

## Clonando o repositório

```bash
git clone https://github.com/Mcaua7/QUIZZEC.git
```

```bash
cd QUIZZEC
```

---

## Instalando as dependências

Após entrar na pasta do projeto, instale as dependências:

```bash
npm install
```

Ou, se preferir usar yarn:

```bash
yarn install
```

---

## Executando o projeto

Para iniciar o projeto com Expo, execute:

```bash
npx expo start
```

Após iniciar, você pode:

* Escanear o QR Code com o aplicativo Expo Go no celular
* Pressionar `a` para abrir no emulador Android
* Pressionar `i` para abrir no simulador iOS (macOS)
